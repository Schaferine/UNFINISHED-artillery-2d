This Project is currently under development.

The project demonstrates the practice of Projectile Motion through the use of artillery, specifically the 105mm howitzer.

The project consists of two repositories: The first is the 2D version (this one), and the second is the 3D version (not yet released)

As of the day and time of this writing (22:06 GMT+8, October 10, 2026),
the only parts that are complete in this project are the drawing of an artillery piece in 2D,
and the file preparations for both of the repositories.
